How this works

Each morning a script checks the public Instagram posts of the venues, bands and promoters on our list. Claude reads the captions and Korean posters and pulls out the date, time, venue, lineup and price. Duplicate posts about the same show get merged.

It gets things wrong sometimes, so always tap through to the original post before you head out. Shows marked check post were harder to read.

Keep b1.shows running

b1.shows is free, ad-free and run by one person. Reading the posters every day costs a little each month. If it helped you find a good night out, you can chip in.
